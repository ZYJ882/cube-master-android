# 魔方大师 Android（3×3 首版）

`魔方大师` 是一个**原生 Android** 三阶魔方工具。当前 **1.1.3 逐面录入易用版**以离线使用为目标，集成三维浏览、手动上色、相机辅助采样、设备端两阶段求解，以及按可调速度执行的还原演示。

## 1.1.3 上色与校正易用性更新

上色模块已从字母记号和小型色板改为普通用户可直接理解的流程。用户可选择“从头录入”，随后按照 **白、红、绿、黄、橙、蓝** 六个面的顺序，在清晰的九宫格中填入真实颜色；填写完一面会自动跳转下一面。颜色按钮同时显示该颜色的 `x / 9` 计数，中心格清楚标记为固定中心块。识图结果也以颜色名称而非 `U/R/F/D/L/B` 记号呈现。若手动录入未填完，应用会阻止求解并指出需要继续完成九宫格。

## 1.1.2 三维交互优化

本版本重做三维魔方控制。现在可以**连续拖拽环绕**，手指松开后镜头会按速度惯性滑行；在展示区双击可回到主视角，不会再因一次轻微划动而误触复位。还原播放改为真实的**逐面缓动旋转动画**：每一步会先完成 90° 或 180° 面层旋转，再提交状态并进入下一步；速度控制条同时影响动画时长和步骤间隔。

## 1.1.1 求解与打乱修复

本版本修复了首次求解可能长时间停留在“正在预计算并搜索”的反馈问题。应用现在会在启动后**后台预热**求解器；求解过程中可再次点击“取消计算”立即返回操作界面；已复原状态将直接显示零步结果。对于“随机打乱”，应用仅从已复原状态施加 22 步合法面转动，并禁止连续同面和同轴转动，同时保存其**逆序还原路线**，因此随机打乱状态保证可还原，且无需等待求解器即可直接播放还原。

## 1.1.0 视觉更新

本版本将界面整体改造为**液态玻璃**风格：使用深空流体渐变背景、半透明高光卡片、冰蓝与薄荷色强调、统一的玻璃分段控件，以及带引导网格的沉浸式相机扫描弹窗。应用启动图标也更换为无文字的立体液态玻璃魔方图案，并已纳入 APK 资源。

## 功能概览

| 模块 | 首版实现 |
|---|---|
| 三维浏览 | 透视投影三维魔方置于液态玻璃展示台中。连续拖拽可环绕浏览，松手后惯性滑行，双击复位视角。 |
| 手动操作 | 提供 `U/R/F/D/L/B` 顺、逆时针按钮；可生成 22 步受约束随机打乱，并保存逆序还原路线。 |
| 手动上色 | 按白、红、绿、黄、橙、蓝六个真实颜色逐面填写九宫格；自动跳面并显示每色 `x / 9` 计数。 |
| 相机识图 | 使用后摄像头的九宫格区域采样颜色，可逐面保存并在上色面板中复核。 |
| 求解校验 | 求解前检查颜色数量、中心块、棱翻转、角朝向、重复块和奇偶性。 |
| 离线求解 | 内置 Kociemba 两阶段算法实现；启动后后台预热，支持取消等待，无网络连接时也可计算高效解法。 |
| 还原演示 | 以逐面缓动旋转展示标准记号，支持单步、开始/暂停、再次演示，以及 `×1`–`×10` 速度调节。 |

> 相机识别受环境光、反光和拍摄角度影响。应用会将识别出的九格填入可编辑面板，建议在求解前检查每种颜色是否恰好为 9 个，并确认相邻面的朝向。

> 内置的两阶段算法以快速、短步骤解法为设计目标；它并不声称对每一个状态均给出数学上严格的全局最短（God's Number）解。

## 快速使用

1. 打开应用后，可直接使用“随机打乱”，或按真实魔方状态手动上色。
2. 如使用“相机识图”，每次只拍摄一个面，将该面九格对准取景框后保存；随后在手动上色面板复核。
3. 点击“计算高效解法”。若状态无效，界面会明确指出颜色数、朝向或奇偶性问题。
4. 解法生成后，可选择“单步”学习动作，或选择“开始还原”播放动画。拖动速度控制条可调整播放速度。

## 编译

工程使用 Java、AndroidX、CameraX 和 Material Components，目标 Android SDK 为 35。

```bash
export ANDROID_HOME=/path/to/android-sdk
./gradlew :app:assembleDebug
```

调试 APK 位于：

```text
app/build/outputs/apk/debug/app-debug.apk
```

### 安装

通过 USB 调试安装时可使用：

```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

也可以将 APK 传到 Android 设备后打开安装。由于这是调试签名包，设备可能需要允许该来源安装未知应用。
