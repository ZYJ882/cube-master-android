# 魔方大师 CubeMaster Android

> 面向 Android 的原生三阶魔方工具：3D 浏览、手动上色、相机识图、离线求解与平滑还原动画。

**仓库名称：** `cube-master-android`  
**项目简介：** 一款以普通用户操作习惯为中心设计的 3×3×3 魔方 App，支持实时三维预览、逐面颜色录入、相机辅助识图、合法性校验、离线高效求解和可调速还原演示。

## 项目亮点

应用采用 Kotlin/Java 原生 Android 工程实现，核心求解过程完全在设备端运行，不依赖网络服务。用户可以拖拽环绕浏览三维魔方，逐面填写九宫格颜色，或通过相机按面采样后复核；应用会在求解与还原前检查颜色数量、中心块、棱块、角块朝向和奇偶性。

可滑动、可扭层的 **3D 魔方是唯一主状态**。下方上色和相机识图会直接更新这一状态：已填写格保留颜色，未填写格显示灰色，灰色状态同样可继续浏览、拖动和扭层。顶部“同步上色”可再次将下方九宫格写入模型；仅在用户点击计算或开始还原时，应用才检查是否仍有灰色格以及当前状态是否可还原。随机打乱和每一次手动层转都会保留逆序路线；此类“即时反向还原”不依赖求解器预热，也允许灰色未填格按用户刚才的层转记录退回操作前状态。

直接触控时，拖动魔方周围空白区域控制视角。应用会先把屏幕拖动转换为被触摸面的局部行、列方向，再根据当前投影视角计算正反向：上/中/下排沿本地行拖动选择上/中/下层，左/中/右列沿本地列拖动选择左/中/右层。层转会跟手预览、锁定方向并在松手后吸附到 `0°` 或 `90°`；完成后才提交状态并清除旧解法。任何手动层转、上色或识图会立即取消当前计算；应用只会在用户点击“计算高效解法”后开始搜索。展示区右上角的 `3D` 按钮支持按住拖动调整并保留视角，`◉` 按钮支持临时预览，松手后自动回到拖动前的视角。

## 快速使用

安装 APK 后，用户可以选择“识图”采样真实魔方，也可以在“逐面录入”中按照白、红、绿、黄、橙、蓝六个中心色填写九宫格。填写过程中，每种颜色最多允许 9 格；完成后点击“计算高效解法”。开始还原前，应用会自动检查当前状态是否真实可还原。

点击三维展示区上方的“同步上色”可以将当前录入状态写入三维主模型。灰色面片代表尚未填写，不代表真实魔方颜色；灰色状态仍能继续扭层。只要是刚刚通过“打乱”或手动层转产生的状态，均可直接点击“开始还原”按反向记录返回，不必等待求解器准备完成。

## 本地构建

需要 Android SDK、JDK 17 或更高版本。进入工程根目录执行：

```bash
./gradlew :app:assembleDebug
```

生成文件位于 `app/build/outputs/apk/debug/app-debug.apk`。Windows 环境使用 `gradlew.bat :app:assembleDebug`。

## 工程结构

| 路径 | 内容 |
|---|---|
| `app/src/main/java/com/manus/cubemaster/` | 原生界面、3D 视图、相机识图、上色流程和状态模型。 |
| `app/src/main/java/com/manus/cubemaster/solver/` | 离线两阶段求解器。 |
| `app/src/main/res/` | Android 主题、颜色、启动图标与资源。 |
| `versions/` | 各交付版本的 APK、源码归档、校验和与版本说明。 |
| `THIRD_PARTY_LICENSES.md` | 第三方求解器及相关许可文本。 |
