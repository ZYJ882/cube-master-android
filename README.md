# 魔方大师 Android（3×3 首版）

`魔方大师` 是一个**原生 Android** 三阶魔方工具。首版以离线使用为目标，集成三维浏览、手动上色、相机辅助采样、设备端两阶段求解，以及按可调速度执行的还原演示。

## 功能概览

| 模块 | 首版实现 |
|---|---|
| 三维浏览 | 透视投影三维魔方。单指拖拽可从不同角度查看，轻点可复位视角。 |
| 手动操作 | 提供 `U/R/F/D/L/B` 顺、逆时针按钮；也支持生成 22 步随机打乱。 |
| 手动上色 | 选择待编辑面与颜色后点按面片；中心块锁定为标准 `URFDLB` 配色。 |
| 相机识图 | 使用后摄像头的九宫格区域采样颜色，可逐面保存并在上色面板中复核。 |
| 求解校验 | 求解前检查颜色数量、中心块、棱翻转、角朝向、重复块和奇偶性。 |
| 离线求解 | 内置 Kociemba 两阶段算法实现；无网络连接时也可计算高效解法。 |
| 还原演示 | 显示标准记号，支持单步、开始/暂停、再次演示，以及 `×1`–`×10` 速度调节。 |

> 相机识别受环境光、反光和拍摄角度影响。应用会将识别出的九格填入可编辑面板，建议在求解前检查每种颜色是否恰好为 9 个，并确认相邻面的朝向。

> 内置的两阶段算法以快速、短步骤解法为设计目标；它并不声称对每一个状态均给出数学上严格的全局最短（God's Number）解。

## 快速使用

1. 打开应用后，可直接使用“随机打乱”，或按真实魔方状态手动上色。
2. 如使用“相机识图”，每次只拍摄一个面，将该面九格对准取景框后保存；随后在手动上色面板复核。
3. 点击“计算高效解法”。若状态无效，界面会明确指出颜色数、朝向或奇偶性问题。
4. 解法生成后，可选择“单步”学习动作，或选择“开始还原”播放动画。拖动速度控制条可调整播放速度。

## 编译

工程使用 Java、AndroidX、CameraX 和 Material Components，目标 Android SDK 为 35。

```bash
export ANDROID_HOME=/path/to/android-sdk
./gradlew :app:assembleDebug
```

调试 APK 位于：

```text
app/build/outputs/apk/debug/app-debug.apk
```

### 安装

通过 USB 调试安装时可使用：

```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

也可以将 APK 传到 Android 设备后打开安装。由于这是调试签名包，设备可能需要允许该来源安装未知应用。

| 求解回归 | 对一个 10 步可达打乱状态，生成 19 步解法并还原到已复原状态。 |
