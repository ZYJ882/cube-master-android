# 魔方大师 CubeMaster Android

> 面向 Android 的原生三阶魔方工具：3D 浏览、手动上色、相机识图、离线求解与平滑还原动画。

**仓库名称：** `cube-master-android`  
**项目简介：** 一款以普通用户操作习惯为中心设计的 3×3×3 魔方 App，支持实时三维预览、逐面颜色录入、相机辅助识图、合法性校验、离线高效求解和可调速还原演示。

## 项目亮点

应用采用 Kotlin/Java 原生 Android 工程实现，核心求解过程完全在设备端运行，不依赖网络服务。用户可以拖拽环绕浏览三维魔方，逐面填写九宫格颜色，或通过相机按面采样后复核；应用会在求解与还原前检查颜色数量、中心块、棱块、角块朝向和奇偶性。

可滑动、可扭层的 **3D 魔方是唯一主状态**。下方上色和相机识图会直接更新这一状态：已填写格保留颜色，未填写格显示灰色，灰色状态同样可继续浏览、拖动和扭层。顶部“同步上色”可再次将下方九宫格写入模型；只有在颜色完整、状态合法时，用户点击“计算高效解法”才会对**当前面片状态**执行选定路线。应用不会把用户此前的动作倒放充当解法。Kociemba 两阶段搜索所需的坐标和剪枝表已在构建期生成并内置于 APK，设备端只加载并校验资源，不会在每次启动时重新生成整套查表。求解区提供七种可对任意完整合法状态实际执行的独立方法：**高效计算机解（Kociemba 两阶段）**、**真实入门层先法**、**真实 CFOP**、**真实 Roux**、**真实棱先**、**真实角先** 和 **真实 ZZ**。其中 Roux 实际构建 First Block、Second Block、CMLL 和仅 M/U 的 LSE；棱先先完成并验证全部 12 条棱，再用保持棱不变的纯角宏完成 8 个角；角先先完成并验证全部 8 个角，再用保持角不变的纯棱宏完成 12 条棱；ZZ 实际完成 EOLine、受限 R/L/U 的 F2L、OCLL 与 PLL。所有独立方法均在每个阶段结束后对主魔方状态验证目标，不会把 Kociemba 动作改名后伪装成其他方法。

直接触控时，拖动魔方周围空白区域控制视角。应用会先把屏幕拖动转换为被触摸面的局部行、列方向，再根据当前投影视角计算正反向：上/中/下排沿本地行拖动选择上/中/下层，左/中/右列沿本地列拖动选择左/中/右层。层转会跟手预览、锁定方向并在松手后吸附到 `0°` 或 `90°`；完成后才提交状态并清除旧解法。任何手动层转、上色或识图会立即取消当前计算；应用只会在用户点击“计算高效解法”后开始搜索。展示区右上角的 `3D` 按钮支持按住拖动调整并保留视角，`◉` 按钮支持临时预览，松手后自动回到拖动前的视角。

## 快速使用

安装 APK 后，用户可以选择“识图”采样真实魔方，也可以在“逐面录入”中按照白、红、绿、黄、橙、蓝六个中心色填写九宫格。填写过程中，每种颜色最多允许 9 格；完成后点击“计算高效解法”。开始还原前，应用会自动检查当前状态是否真实可还原。

点击三维展示区上方的“同步上色”可以将当前录入状态写入三维主模型。灰色面片代表尚未填写，不代表真实魔方颜色；灰色状态仍能继续扭层。完成上色或打乱后，可在“选择还原策略”中选择 Kociemba、真实入门层先法、真实 CFOP、真实 Roux、真实棱先、真实角先或真实 ZZ。棱先会先验证全部 12 条棱，再以严格保持棱块的纯角宏完成角块；角先会先验证全部 8 个角块，再以严格保持角块的纯棱宏完成棱块。Roux 会依次构建两个 1×2×3 块、CMLL 与仅 M/U 的最后六棱；ZZ 会先完成全部棱定向与 DF/DB Line，后续 F2L、OCLL、PLL 限制为 R/L/U。七种方法均只在当前颜色完整且状态合法时计算，各独立阶段都会在主状态上校验目标。如果内置查表资源无法在 8 秒内加载，界面会明确提示失败并可重试，不会无限等待。

## 本地构建

需要 Android SDK、JDK 17 或更高版本。进入工程根目录执行：

```bash
./gradlew :app:assembleDebug
```

生成文件位于 `app/build/outputs/apk/debug/app-debug.apk`。Windows 环境使用 `gradlew.bat :app:assembleDebug`。
