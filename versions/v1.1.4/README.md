# CubeMaster Android v1.1.4 — 紧凑九宫格版

**版本：** v1.1.4  
**项目：** 魔方大师 CubeMaster Android

## 版本简介

修复手机端九宫格被拉伸成长条的问题，改为居中的 3×3 固定小正方形，并将颜色选择器压缩为单行色块。

| 文件 | 用途 |
