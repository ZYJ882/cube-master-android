# CubeMaster Android v1.1.29

## Roux 阶段稳定性与进度修复版

本版修复了“真实 Roux”在部分状态下看似长期停留在总计算提示、或在 LSE 后仍报告未复原的问题。根因是 LSE 的 CubieCube 阶段目标只描述角块和棱块，而应用的主状态还会保留 `M` 切片带动的中心朝向。此前搜索可能命中“六棱与四角已归位、四枚中心仍转位”的假终点，随后主状态完整比较失败；现在 LSE 搜索会同时要求 `M` 切片中心周期回到复原朝向，最终主状态才允许报告成功。

| 场景 | v1.1.29 行为 |
|---|---|
| First Block | 真实规划左侧 `1×2×3` 块，并在阶段开始时显示当前进度。 |
| Second Block | 真实保留左块并规划右侧 `1×2×3` 块；界面显示“第 2/4 阶段”。 |
| CMLL | 仅在满足两个 Block 约束的动作空间内完成顶层四角，界面显示“第 3/4 阶段”。 |
| LSE | 仅使用 `M/U` 完成最后六棱；除了棱角目标外，额外要求 M 切片中心回到复原朝向。 |
| 取消或 12 秒保护 | 深度搜索每层检查线程中断；已取消任务会立即退出，不会阻塞下一次计算。 |

## 回归验证

| 检查 | 结果 |
|---|---|
| 受影响案例 1：`R U R' U' F2 D L2 B U2 R2 F' L D2 B2 U' R F2` | 之前在 LSE 后报告“未完成整颗魔方复原”；现以 41 步完整复原。 |
| 受影响案例 2：`U2 R2 F2 D2 L2 B2 U R' F D' L B' U2 R2` | 之前在 LSE 后报告“未完成整颗魔方复原”；现以 44 步完整复原。 |
| 中层混合状态：`M E' S2 R U' F2` | 在计算前按中心颜色面对齐后，Roux 以 3 步完整复原。 |
| 40 组固定种子的合法 25 步打乱 | 40/40 完整复原；桌面回归最慢 165 ms，未出现假完成、超时或遗留任务。 |
| 动作模型一致性 | `U/R/F/D/L/B/M` 的顺、逆、二次转动均确认 CubeState 与 StageSearch 的角块、棱块及朝向变换一致。 |
| Android Debug 构建 | 通过。 |
