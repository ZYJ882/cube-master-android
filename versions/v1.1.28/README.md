# CubeMaster Android v1.1.28

## 中心随层转动与计算前面对齐版

本版按真实魔方操作规则修复中层 `M`、`E`、`S`：中心块会随被转动的层同步移动和变换颜色位置；不会在动画或主状态中被强制固定。用户点击计算时，应用才根据当前六个中心颜色把整个状态自动旋转到标准 `URFDLB` 面向，再执行合法性校验和所选求解器。

| 时机 | 行为 |
|---|---|
| 手动拖动 `M/E/S` | 中心贴纸、周围棱块贴纸和中层小块体积使用相同轴与角度同步旋转。 |
| 手势提交 | 三维主状态与下方上色草稿应用同一个中层动作，当前中心颜色位置保持可见。 |
| 点击计算 | 检查未知色块后，以当前中心颜色整体面对齐到标准坐标，刷新界面后再校验与求解。 |
| 还原播放 | 在对齐后的单一状态中播放真实求解器步骤，不混入旧朝向。 |

## 回归验证

| 检查 | 结果 |
|---|---|
| `M/M2/M′`、`E/E2/E′`、`S/S2/S′` | 每种动作均确认至少一个中心随层转动；计算前面对齐后通过合法性校验。 |
| 混合状态 `M E′ S2 R U′ F2` | 面对齐后由两阶段求解器以 18 步完整复原。 |
| Android Debug 构建 | 通过。 |
| 可复用技能 | `rubiks-center-follow-turn` 已创建并通过结构校验。 |
