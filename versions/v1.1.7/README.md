# CubeMaster Android v1.1.7 — 直接触控扭层版

**版本：** v1.1.7  
**项目：** 魔方大师 CubeMaster Android

## 版本简介

本版本增加直接触控扭层功能。拖动魔方模型周围的空白区域可以控制视角；按住并拖动可见的魔方层会识别对应面，并执行该面顺时针或逆时针平滑扭动。动画完成后才提交 CubeState，随后清除旧解法，避免三维模型、状态模型和求解结果不一致。

## 操作说明

| 手势 | 功能 |
|---|---|
| 拖动魔方周围空白区域 | 环绕控制视角，松手后继续惯性滑行。 |
| 拖动魔方可见面片 | 扭动被拖动面对应的魔方层。拖动方向决定顺时针或逆时针。 |
| 双击空白区域 | 恢复默认视角。 |
