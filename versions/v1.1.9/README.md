# CubeMaster Android v1.1.9 — 全层手势与显式求解修复版

**版本：** v1.1.9  
**项目：** 魔方大师 CubeMaster Android

## 修复内容

本版本针对直接手势扭层和手动操作后的求解状态进行修复。此前的手势只按可见面整体处理，因此中排、上排等位置的操作很难得到预期响应；本版改为按被按住贴纸的行列选择实际层。

| 操作区域 | 拖动方向 | 可选择的层 |
|---|---|---|
| 可见面的上排 / 中排 / 下排 | 横向拖动 | 上层 / 中层 / 下层。 |
| 可见面的左列 / 中列 / 右列 | 纵向拖动 | 左层 / 中层 / 右层。 |

中层切片 `M`、`E`、`S` 已纳入状态模型和三维动画。求解前应用会按中心块方向规范化状态，以便继续使用离线两阶段求解器。

## 求解控制

计算解法只会在用户主动点击**“计算高效解法”**时启动。任何手动层转、手动上色、识图导入、打乱或复位都会立即取消正在进行的计算并清除旧解法；后台预热不会改变为“正在计算”状态。
