# CubeMaster Android v1.1.36

## 下白前绿与角先播放一致性版

本版根据实际录屏修复了角先“步骤已经生成并播放完成，但魔方仍未复原”的问题，并将默认三维观察约定固定为**下白、前绿**。

## 根因与修复

角先的纯棱收尾可以包含 `M/E/S` 中层动作。此前播放循环在**每一步**开始时都再次调用中心面对齐。面对齐本应只在用户点击“计算”时执行一次；若在收尾中途执行，它会整体重映射当前面片，改变中层状态，使后续原本正确的动作不再对应当前魔方。

| 项目 | v1.1.36 行为 |
|---|---|
| 计算前 | 仍只在用户点击计算时，按六个中心颜色进行一次整体面对齐。 |
| 动画播放中 | 不再执行任何中心面对齐；所有动作连续应用在同一主状态。 |
| 动画最后一步 | 强制核验 `CubeState.SOLVED`；未复原时显示错误，而不会把错误状态报告为完成。 |
| 默认三维镜头 | 下白、前绿，黄色位于上方；双击模型复位也回到同一姿态。 |
