# CubeMaster Android v1.1.8 — 跟手层转与双视角控制版

**版本：** v1.1.8  
**项目：** 魔方大师 CubeMaster Android

## 版本简介

本版本对直接扭层进行深度重构。用户拖动可见魔方层时，模型会先按手指方向跟手旋转；方向会在小距离拖动后锁定，避免斜向移动频繁切换轴向。松手后，角度不足会平滑回弹至 `0°`，达到提交阈值则自然吸附至 `90°` 或 `-90°`，随后才向状态模型提交一次标准面转动。

为了提高实际手机操作的稳定性，面片命中范围覆盖了贴纸之间的窄间隙；动画被取消、重置或进入其他操作时不会错误提交面转动。

## 视角控制

| 控件 / 手势 | 行为 |
|---|---|
| 拖动模型周围空白区域 | 直接环绕视角，松手后可惯性滑行。 |
| `3D` 按钮 | 按住并拖动控制视角，松手后保留调整后的视角。 |
| `◉` 按钮 | 按住并拖动临时预览视角，松手后以短缓动恢复按下前的视角。 |
| 拖动可见魔方层 | 进入跟手层转预览，松手后回弹或吸附并提交。 |
| 双击空白区域 | 恢复默认相机视角。 |
