# CubeMaster Android v1.1.18 — 层先法面板稳定修复版

**版本：** v1.1.18  
**项目：** 魔方大师 CubeMaster Android

## 修复的问题

在 v1.1.17 中，部分设备点击“计算真实层先法”后，下方“计算与还原”卡片可能在动态结果更新时消失。该问题会让用户看不到计算进度、错误说明、步骤和播放控件，属于界面稳定性缺陷。

本版本将真实层先法计算与求解卡片展示分开保护：即使后台算法失败、超时或产生异常步骤规模，主页面及求解面板也必须保持可见和可操作。

| 防护项 | v1.1.18 行为 |
|---|---|
| 动态结果卡片 | 求解卡片改用非软件缓存绘制层；内容更新前后强制保持可见、请求重测量并重绘。 |
| 计算超时 | 每次求解有 12 秒保护时间；到时停止等待，保留页面并显示可读提示。 |
| 异常步骤规模 | 真实层先法单阶段超过 160 步或总计超过 360 步时安全停止，不生成过大文本或播放队列。 |
| 成功 / 取消 / 失败 | 三种回调均强制恢复求解卡片；不会因后台异常留下空白区域。 |

## 保持不变的还原规则

本版没有把层先法退回为 Kociemba 动作改名。真实入门层先法仍需依次达到并验证以下目标：底层十字、完成首层、完成中层、顶层十字、顶层朝向、顶层排列并复原。

## 验证

已用用户截图中显示的 22 步高效解对应状态复现层先法规划。六个阶段分别生成 13、41、31、6、8、22 步，共 121 步，宿主回归耗时约 47 ms；Android 工程完整构建成功。
