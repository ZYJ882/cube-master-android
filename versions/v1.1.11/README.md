# CubeMaster Android v1.1.11 — 上色草稿与真实状态分离版

**版本：** v1.1.11  
**项目：** 魔方大师 CubeMaster Android

## 状态分离规则

本版本将下方逐面上色和上方真实魔方彻底分离。下方九宫格不再直接覆盖三维魔方的状态，也不会阻止随机打乱、直接扭层、计算解法或开始还原。

| 操作 | 行为 |
|---|---|
| 在下方九宫格上色 | 只写入独立的上色草稿。 |
| 点击“刷新上色” | 上方 3D 魔方临时显示草稿；已填写格显示颜色，未填写格显示灰色。 |
| 开始计算 / 开始还原 | 自动退出草稿预览，使用真实魔方状态。 |
| 打乱 / 复位 / 手动扭层 | 自动退出草稿预览，继续操作真实魔方。 |
| 识图 | 识图结果写入草稿对应面；点击“刷新上色”才显示。 |

因此，即使上色草稿仍是 `0 / 48`，已随机打乱或已手动扭动的真实魔方仍可正常计算和还原。随机打乱仍会直接保留逆序路线，不会等待上色草稿完成。
