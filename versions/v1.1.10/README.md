# CubeMaster Android v1.1.10 — 局部坐标方向修复版

**版本：** v1.1.10  
**项目：** 魔方大师 CubeMaster Android

## 修复内容

本版本修复了上下滑动在不同可见面上出现反向、选错层或无预期响应的问题。此前实现直接以屏幕 `dx/dy` 判断层级；当用户转动相机后，侧面、顶面和底面的屏幕方向会发生透视变化，导致同样的上下滑动落到错误轴向。

新版处理流程如下：

1. 先依据被触摸贴纸所属面，计算该面的本地“沿行”和“沿列”方向。
2. 将手指在屏幕上的拖动投影到这两个本地方向，选择用户真正沿着的行或列。
3. 由被触摸贴纸的行/列选择上、中、下层或左、中、右层。
4. 将拖动继续投影到该层标准正向旋转的屏幕切线，统一确定顺时针与逆时针。

因此，用户改变视角后，前面、侧面、顶面和底面的上下/左右手势仍遵循相同的层选择和方向语义。

## 回归验证

已验证外层与中层 `U/E/D`、`L/M/R`、`F/S/B` 的正反转都可逆，且各层组合可在进入离线求解前规范化为标准中心朝向。
