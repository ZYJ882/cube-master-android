# CubeMaster Android v1.1.31

## 棱先与角先困难状态稳定版

本版修复 v1.1.30 在部分真实合法状态上可能显示“求解未完成”的问题。用户截图中的两类失败分别是：角先在“棱组 3/4”找不到保持八角不变的纯棱宏路径，以及棱先在“棱组 4/4”超过初始外层阶段的搜索深度。

| 失败位置 | 根因 | v1.1.31 修复 |
|---|---|---|
| 真实角先 · 棱组 3/4 | 纯棱宏双向搜索只允许四层宏拼接，某些合法残余棱状态需要更深的保持角路径。 | 纯宏双向搜索提升为五层；保持全部八角与六个中心的校验继续强制执行。 |
| 真实棱先 · 棱组 4/4 | 最后棱组只以初始深度进行外层阶段搜索，部分状态需要更深的受约束路径。 | 如果初始迭代完整结束仍未找到路径，将在同一个总安全预算内自动加深一次，最高搜索深度为 30。 |

## 保持的安全边界

内部总规划预算调整为 10 秒，仍低于主界面 12 秒取消保护。每个外层重试、纯宏搜索和阶段提交都响应线程取消；超时不会锁住下一次计算。棱先的纯角阶段仍必须保持全部 12 条棱，角先的纯棱阶段仍必须保持全部 8 个角，最终继续以主状态完整复原作结论。
