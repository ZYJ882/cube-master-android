# CubeMaster Android v1.1.37

## 角先纯棱宏播放门控版

本版修复“角先已播放公式但未还原，随后提示六个中心块必须保持标准配色”的实际问题。

角先的第二阶段会使用纯棱宏，例如 `M' R U' M U R'`。这类宏在**中间单步**会暂时让中心贴纸离开标准坐标，但在宏最后一步会恢复中心；这是正常的中层转动过程。此前自动播放每一步、以及单步播放每一步，都会重新执行“六个中心必须标准”的起始合法性校验，导致宏刚进行到中途就被错误拦截，后续恢复中心与完成棱块的动作未执行。

| 场景 | v1.1.37 行为 |
|---|---|
| 点击开始还原的首步 | 校验输入完整性、可解性和计算前面对齐后的标准中心。 |
| 纯角/纯棱宏中间单步 | 允许中心暂时移动，不重复执行起始合法性门控。 |
| 自动播放暂停后继续 | 从当前真实状态继续，不因临时中心状态被误拦截。 |
| 单步播放 | 只在第 1 步校验；宏中途可继续到恢复中心。 |
| 最后一步 | 强制核验 `CubeState.SOLVED`，未复原时绝不报告成功。 |
