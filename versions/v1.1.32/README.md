# CubeMaster Android v1.1.32

## 棱先与角先移动端进度与预热版

本版处理“选择真实棱先或真实角先后，界面一直显示同一条正在计算提示”的移动端体验问题。此前首次点击可能同时触发纯角、纯棱宏的构建，并在宏双向搜索内反复逐动作展开一条宏；在手机上这会让用户长时间只看到总提示，难以判断是否仍在计算。

| 优化 | 行为 |
|---|---|
| 后台预热 | 用户选择真实棱先或真实角先后，应用立即在后台构建并验证纯角、纯棱宏；完成前不进入 12 秒实际求解窗口。 |
| 预组合宏变换 | 每条纯宏在预热时合成为一个 CubieCube 变换；搜索时不再重复逐个展开宏内的 10～30 个面转。 |
| 实时阶段回调 | 棱先实时显示 `棱组 1/4` 到 `角组 4/4`，共 8 阶段；角先实时显示“完整八角”与 `棱组 1/4` 到 `棱组 4/4`，共 5 阶段。 |
| 取消与约束 | 所有阶段继续响应取消；棱先纯角阶段必须保持 12 棱，角先纯棱阶段必须保持 8 角。 |

## 回归验证

| 检查 | 结果 |
|---|---|
| 纯宏预热 | 完成时间 76 ms（桌面回归），不计入用户点击后的求解保护窗口。 |
| 原先困难状态 | 棱先 1216 ms、角先 795 ms；均完整复原。 |
| 3 组代表性难度状态 | 两种路线均完整复原；实时回调完整输出所有 8 或 5 个阶段。 |
| Android Debug 构建 | 通过。 |
| APK 签名 | 已通过 v2 签名验证。 |
