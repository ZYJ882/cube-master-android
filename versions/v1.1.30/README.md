# CubeMaster Android v1.1.30

## 真实棱先与真实角先独立策略版

本版新增两种经典三阶魔方路线：**真实棱先（Edges First）** 与 **真实角先（Corners First）**。二者均由独立分阶段搜索与受保持约束的宏动作生成，不调用 Kociemba 完整解，也不会把其他求解器步骤改名显示。

| 策略 | 第一宏阶段 | 第二宏阶段 | 阶段保持约束 |
|---|---|---|---|
| 真实棱先 | 使用外层受约束搜索，逐组定位并定向全部 12 条棱。 | 使用纯角宏逐组完成全部 8 个角。 | 每个纯角宏在构建时验证：12 条棱和六个中心均不变。 |
| 真实角先 | 使用完整八角排列坐标与八角朝向坐标，先完成全部 8 个角。 | 使用纯棱宏逐组完成全部 12 条棱。 | 每个纯棱宏在构建时验证：8 个角和六个中心均不变。 |

## 路线与界面

求解策略面板新增“真实棱先”和“真实角先”。棱先的动画阶段依次显示四组棱与四组角；角先先显示“完整八角”，随后显示四组棱。每段动作提交前后都在 CubieCube 目标与 CubeState 主状态上复核；播放仍支持单步、自动还原、调速和 12 秒界面保护。

本版同时修复 `CubeState.parseMoves()` 只接受外层动作的问题。文本动作序列现在也会正确解析 `M`、`E`、`S` 及其二次、逆转形式，因此中层宏、Roux LSE 回归和状态验证不会再静默遗漏中层动作。

| 检查 | 结果 |

| 路线约束 | 棱先在纯角阶段保持全部棱；角先在纯棱阶段保持全部角。 |
| Android Debug 构建 | 通过。 |

## 参考定义

棱先的定义为在任何角块之前解完全部棱；角先的定义为在任何其他部分之前使全部角块彼此相对复原。[1][2]
