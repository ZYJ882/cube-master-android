# CubeMaster Android v1.1.13 — 即时反向还原修复版

**版本：** v1.1.13  
**项目：** 魔方大师 CubeMaster Android

## 本次修复

本版本修复了手动扭动魔方层后，界面仍提示“求解器正在后台准备”、用户无法立即开始还原的阻塞问题。现在每一次通过三维手势或“手动转动”按钮完成的真实层转，都会被记录为一条**即时反向还原路线**。点击“开始还原”后，应用直接按相反顺序播放这些层转，不调用、也不等待离线两阶段求解器。

| 场景 | v1.1.13 行为 |
|---|---|
| 点击“打乱” | 生成合法层转序列并立即保留其逆序，直接可播放。 |
| 三维模型上拖动并完成层转 | 松手吸附后记录该步，并立即更新反向路线。 |
| 点击手动转动栏的面 / 中层按钮 | 记录该步并立即启用“开始还原”。 |
| 求解器仍在预热 | 不阻塞随机打乱或手动层转的反向播放。 |
| 有灰色未填格 | 仍可播放用户刚刚产生的逆序历史，退回操作前状态。 |
| 点击“计算高效解法” | 仍只在完整、可校验状态下调用两阶段求解器，生成通用解法。 |

> 即时反向还原的目的，是可靠地撤销应用已经记录的合法层转；它不同于对任意手动录入状态的完整求解。对于识图或上色形成的完整魔方状态，仍应使用“计算高效解法”。

## 回归验证

已验证以下两类即时反向路线：完整颜色魔方，以及带 **48 个灰色未知面片** 的状态。测试覆盖 `U/R/F/D/L/B` 外层和 `M/E/S` 中层的正转、逆转与二转；对历史步骤取逆序回放后，面片状态精确恢复至操作前，灰色未知面片数量保持不变。Android 工程同时完成构建与 APK 签名校验。
