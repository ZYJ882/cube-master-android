# CubeMaster Android v1.1.38

## 底白前绿与全方法播放守卫版

本版统一默认三维观察和所有还原方法的播放安全策略。

## 默认观察约定

默认打开与双击复位均使用以下物理颜色朝向：

| 方位 | 颜色 | 求解器标准面 |
|---|---|---|
| 底部 | 白色 | `U` |
| 顶部 | 黄色 | `D` |
| 前方 | 绿色 | `F` |
| 后方 | 蓝色 | `B` |
| 左侧 | 橙色 | `L` |
| 右侧 | 红色 | `R` |

这只改变镜头的默认偏航与俯仰角；`URFDLB` 状态坐标、上色、识图和求解器面序保持不变。

## 中层动作风险审计

| 方法 | 是否可能出现 `M/E/S` | 播放策略 |
|---|---|---|
| Kociemba 两阶段 | 否，当前输出仅外层动作 | 首步校验 + 全程连续回放。 |
| 层先法 | 否，当前阶段公式仅外层动作 | 首步校验 + 全程连续回放。 |
| CFOP | 否，当前阶段公式仅外层动作 | 首步校验 + 全程连续回放。 |
| Roux | **是**，LSE 使用 `M/U` | 允许中途中心暂时移动，最后恢复并完整复原。 |
| 棱先 | 否，当前纯角收尾只用外层动作 | 首步校验 + 全程连续回放。 |
| 角先 | **是**，纯棱收尾使用 `M` | 允许中途中心暂时移动，最后恢复并完整复原。 |
| ZZ | 否，当前 EOLine/F2L/OCLL/PLL 仅外层动作 | 首步校验 + 全程连续回放。 |

无论方法是否使用中层动作，求解完成后都会先以 Android 主状态模型逐步回放全部动作。只有最终状态等于完整复原，动作列表才会进入播放面板；播放结束也会再次验证完整复原。
