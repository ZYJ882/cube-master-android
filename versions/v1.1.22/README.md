# CubeMaster Android v1.1.22

## 连续纵向视角修复版

本版修复三维模型在纵向（Y 轴）拖动到一定角度后“划不动”的问题。

此前普通空白区拖拽、`3D` 按住拖拽及惯性动画均把俯仰角硬限制在 `-84°` 至 `84°`；达到边界后，继续上下划动不会再改变模型角度，因此形成明显阈值和卡住感。

本版移除了该硬限制，改为对相机的横向与纵向角度执行 `360°` 连续环绕：

| 操作路径 | 修复后行为 |
|---|---|
| 空白区域上下拖动 | 可连续越过顶部与底部，不会停在原先 `±84°` 的阈值。 |
| `3D` 按住上下拖动 | 使用同一连续环绕逻辑。 |
| 释放后的惯性 | 纵向惯性同样可以自然越过原先边界，再按阻尼停止。 |
| 小眼睛临时预览 | 仍会在松手后回到拖动前记录的相机姿态。 |

角度仅在数值层面规约到等价的 `-180°` 至 `180°` 区间，避免长时间滑动后数值无限增长；三维投影仍基于连续的正弦、余弦旋转，因此不会产生阈值式视觉跳变。拖动越过顶面或底面后，模型会自然翻到对应的背面视角，这是完整环绕的预期行为。
