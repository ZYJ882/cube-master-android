# CubeMaster Android v1.1.14 — 标准两阶段状态求解版

**版本：** v1.1.14  
**项目：** 魔方大师 CubeMaster Android

## 本次修复

本版本按“求解当前魔方状态”的标准方式重整还原流程。手动扭层、随机打乱、上色与识图只更新三维主魔方；随后用户点击“计算高效解法”时，应用会以当前的 54 个面片状态为输入，运行本地 **Kociemba 两阶段算法**。应用不再把此前用户的动作倒放成“解法”。

Kociemba 两阶段方法先将任意合法三阶状态带入子群 `G1 = <U, D, R2, L2, F2, B2>`，再从该子群完成求解；其搜索依赖坐标变换、转动查表和剪枝表。[1] 本版本保留后台初始化坐标和剪枝表的机制，但在初始化尚未完成时，用户点击“计算高效解法”会保留当前请求，并在初始化完成后自动继续标准搜索，而不是提示用户反复点击或切换至动作逆序。

| 场景 | v1.1.14 行为 |
|---|---|
| 手动滑动三维魔方层 | 只更新当前面片状态，并使旧解法失效。 |
| 点击“打乱” | 生成合法状态；随后由两阶段算法重新计算该状态的解法。 |
| 上色或识图 | 直接更新三维主状态；完整且合法后可求解。 |
| 求解器初始化中点击计算 | 保存本次当前状态请求；初始化完成后自动运行 Kociemba 搜索。 |
| 有灰色未填格或状态不合法 | 明确提示需要补全或修正；不会启用还原。 |
| “开始还原” | 仅在 Kociemba 计算并校验成功后启用，播放计算得到的标准记号步骤。 |

> 中层转动可能改变中心块朝向。提交给标准求解器前，应用会先按照中心块对当前三维状态做全局朝向规范化，再进行合法性检查和两阶段搜索。

## 回归验证

已完成 `10` 组端到端验证：一组外层组合状态、一组含 `M/E/S` 中层转动并进行朝向规范化的状态，以及八组固定随机种子的 22 步合法状态。每一组都执行“当前面片状态 → Kociemba 两阶段计算 → 应用返回步骤”，最终精确回到复原态；结果解法长度为 18–23 步。Android 工程已完成构建与 APK 签名校验。
