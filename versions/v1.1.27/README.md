# CubeMaster Android v1.1.27

## 中层立体动画连续性修复版

本版修复 `M`、`E`、`S` 中层手势转动时，贴纸看起来像从魔方核心脱离并悬浮旋转的视觉问题。

### 修复内容

原先的 Canvas 三维预览仅对中层的贴纸四边形应用旋转变换；在 v1.1.26 固定六个视觉中心后，贴纸与静止中心之间缺少中层小块的深色塑料体和侧面连接，造成明显的“薄片穿出核心”错觉。

v1.1.27 为正在转动的九个中层小块补充了完整立方体几何预览：

| 渲染部分 | 新行为 |
|---|---|
| 中层小块体积 | 以九个深色立方体小块绘制，和贴纸使用同一旋转轴、角度、透视投影与深度排序。 |
| 可见侧面 | 根据当前相机视角绘制中层小块的可见深色塑料侧面与轮廓。 |
| 中层贴纸 | 继续跟手旋转并覆盖在旋转小块的外表面。 |
| 固定中心 | 六个中心颜色仍作为核心视觉基准固定显示，不随中层漂移。 |
| 松手吸附 | 仍采用原有 0° / ±90° 平滑吸附；预览几何与最终面片状态保持同一动作方向。 |

### 验证

| 检查 | 结果 |
|---|---|
| M/E/S 动画结构 | 中层体积、固定视觉中心和贴纸预览均已接入同一绘制路径。 |
| `M/M2/M′`、`E/E2/E′`、`S/S2/S′` | 均可在求解前归一化为标准中心并通过合法性校验。 |
| 混合状态 `M E′ S2 R U′ F2` | 两阶段求解器生成 18 步动作并完整复原。 |
| Android Debug 构建 | 通过。 |
