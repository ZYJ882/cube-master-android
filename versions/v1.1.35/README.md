# CubeMaster Android v1.1.35

## 下白上黄默认观察姿态版

本版恢复三维模型的默认观察约定：**白色在下，黄色在上**。此前默认相机俯仰角会从黄色 D 面一侧观察，视觉上形成“下黄上白”的反向习惯。

| 场景 | v1.1.35 行为 |
|---|---|
| 首次打开模型 | 默认镜头以白色 U 面在下、黄色 D 面在上的用户观察姿态展示。 |
| 双击模型复位 | 复位回同一套下白上黄默认姿态。 |
| 打乱、上色、识图、还原播放 | 不会重写用户视角；模型继续使用当前镜头，若手动复位则回到下白上黄。 |
| 中层 `M/E/S` 后计算 | 仍仅在点击计算时进行面向求解器的中心整体对齐；此项不改变默认镜头定义。 |

此修复只修改三维相机默认俯仰角，不改变 `URFDLB` 状态面序、白黄颜色映射、相机识图写入规则、离线求解器坐标或还原动作。
