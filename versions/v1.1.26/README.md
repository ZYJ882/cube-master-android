# CubeMaster Android v1.1.26

## 中层转动中心一致性修复版

本版修复手动转动 `M`、`E`、`S` 中层时，三维模型显示中心颜色随层迁移、之后又被判为不可复原的问题。

### 根因与修复

中层切片在标准魔方坐标中会改变相对观察方向的中心朝向；旧修复曾强行把中心贴纸固定在求解面片状态中，导致棱块置换奇偶性与角块不一致。另一方面，直接将内部中心朝向用于三维显示又会让用户看到中心色块“变色”。

v1.1.26 将这两类职责分离：

| 层级 | 行为 |
|---|---|
| **三维显示与上色界面** | 六个中心块始终以固定面基准颜色显示，且在 `M/E/S` 动画中不随中层移动。 |
| **内部主状态** | 保留中层操作所需的中心朝向记录，保证面片置换与奇偶性仍是物理合法状态。 |
| **点击计算前** | 调用现有中心朝向归一化，将内部状态整体转换回 `URFDLB` 标准中心坐标，然后验证并求解。 |

因此，用户拖动中层时不会再看到中心色块变色；随后可正常计算，不会因中层操作产生“棱块与角块奇偶性不一致”的伪不可解状态。

### 回归验证

| 覆盖 | 结果 |
|---|---|
| `M`、`M2`、`M'`、`E`、`E2`、`E'`、`S`、`S2`、`S'` | 均可归一化为标准中心并通过合法性校验。 |
| 每种中层动作后执行逆转 | 均回到标准复原状态。 |
| 混合中层与外层状态 `M E' S2 R U' F2` | 归一化后由两阶段求解器生成 18 步动作并完整复原。 |
| Android Debug 构建 | 通过。 |
