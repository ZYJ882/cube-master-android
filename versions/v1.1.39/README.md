# CubeMaster Android v1.1.39

## 前左绿面默认构图版

本版只修正默认镜头的左右镜像关系，匹配指定目标构图。

| 项目 | v1.1.39 默认表现 |
|---|---|
| 底面 | 白色。 |
| 顶面 | 黄色。 |
| 正面 | 绿色 `F` 面。 |
| 后面 | 蓝色 `B` 面。 |
| 屏幕构图 | 绿色正面显示为左侧主可见面，橙色左面显示在右侧。 |
| 双击模型复位 | 回到同一前左观察姿态。 |

v1.1.38 使用的前右观察方向会令绿色虽然仍是正面，但显示在屏幕右侧、红色显示在左侧；本版将默认偏航镜像到前左方向，不改变颜色映射、状态坐标、上色、识图、手势层转、求解器或播放逻辑。
