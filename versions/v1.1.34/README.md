# CubeMaster Android v1.1.34

## 快速棱先与角先流程同步版

v1.1.33 已将棱先和角先改为快速完整目标路线，但部分界面说明仍沿用旧的“逐组棱”文案。本版只同步说明与实际执行，避免用户看到与算法不一致的 4/8、3/4 或 1/5 阶段描述。

| 方法 | 实际 v1.1.34 流程 | 界面显示 |
|---|---|---|
| 真实棱先 | 先规划至 **12 条棱全部复原**、角处于纯角中间态；再以保持棱不变的纯角宏完成八角。 | `1/2 完整十二棱` → `2/2 纯角收尾` |
| 真实角先 | 先规划至 **8 个角全部复原**、棱处于纯棱中间态；再以保持角不变的纯棱宏完成十二棱。 | `1/2 完整八角` → `2/2 纯棱收尾` |

棱先和角先依然会先验证目标类别完整达成。收尾宏在构建时验证保持约束，并在阶段结束后重新验证主状态；角先、棱先的独立不排队执行通道与两阶段查表就绪门控继续保留。
