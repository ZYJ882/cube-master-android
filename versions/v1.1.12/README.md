# CubeMaster Android v1.1.12 — 三维主状态与灰色层转版

**版本：** v1.1.12  
**项目：** 魔方大师 CubeMaster Android

## 核心状态规则

本版本以可拖动、可扭层的三维魔方作为唯一主状态。下方九宫格上色和相机识图不再只是临时预览，而是直接更新上方模型；更新后的颜色会持续保留，不会自动回到更新前状态。

| 操作 | 对三维主状态的行为 |
|---|---|
| 下方九宫格上色 | 对应面片立即更新为选定颜色。 |
| 识图导入一面 | 识别到的九格直接更新主模型对应面。 |
| 未填写格 | 显示灰色 `?`，但仍可浏览、拖动视角和扭动上/中/下、左/中/右层。 |
| 手动层转 | 颜色与灰色未知格一起移动，下方九宫格同步更新。 |
| 随机打乱 / 复位 | 主模型更新为对应真实状态，下方九宫格同步刷新。 |
| 计算或还原 | 只有此时才检查灰色未填格、颜色数量、中心、朝向和奇偶性。 |

顶部“同步上色”用于将下方当前九宫格再次明确写入三维主模型。若仍有灰色格，应用会允许继续操作魔方，但会在计算和还原入口提示先补全颜色。

## 回归验证

已验证 48 个灰色未知面片可以随 `U/E/D`、`L/M/R`、`F/S/B` 的正反层转移动，数量保持不变；Android 工程已完成构建与签名校验。
