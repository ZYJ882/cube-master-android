# CubeMaster Android v1.1.17 — 真实层先法修复版

**版本：** v1.1.17  
**项目：** 魔方大师 CubeMaster Android

## 修复说明

v1.1.16 曾把同一条 Kociemba 两阶段动作按“入门分层”“CFOP”“Roux”“ZZ”等名称显示。这只是说明文字不同，不是不同的复原方法，不能满足真正逐层还原的要求。本版本已移除这些伪教学播放选项。

求解区现在只保留两个可对任意完整、合法当前状态实际执行的独立方法：**高效计算机解（Kociemba 两阶段）**和**真实入门层先法**。

| 方法 | 动作来源 | 行为 |
|---|---|---|
| 高效计算机解 | Kociemba 两阶段搜索器 | 直接针对当前状态计算较短的标准记号解法。 |
| 真实入门层先法 | 独立的 Layer-By-Layer 状态机 | 每个阶段完成并验证真实状态目标后，再进入下一阶段。 |

## 真实层先法阶段

层先法不会复用 Kociemba 返回的播放序列。它使用独立的分层状态机，在每阶段后以主魔方的 `URFDLB` 面片状态验证目标。

| 阶段 | 实际状态目标 |
|---|---|
| 1. 底层十字 | 白色十字完成，四个相邻侧面棱块与各自中心色匹配。 |
| 2. 完成首层 | 白色首面与四个对应侧面第一行均正确。 |
| 3. 完成中层 | 首层保持完成，四个侧面第二行棱块均进入正确槽位。 |
| 4. 顶层十字 | 黄色顶层的四条棱块完成朝向。 |
| 5. 顶层朝向 | 顶层九个面片均为黄色。 |
| 6. 顶层排列并复原 | 顶层角块、棱块排列正确，整颗魔方复原。 |

播放时，状态栏会标出当前属于哪个真实层先法阶段。用户切换方法、手动扭层、上色、识图、打乱或复位时，旧步骤与阶段列表会一并清除，不能再被误播放。

## 技术实现与归属

层先法内核基于 Shoumyo Chakravorti 的 MIT 许可开源实现 [`SChakravorti21/Rubiks-Cube-Solver`](https://github.com/SChakravorti21/Rubiks-Cube-Solver) 进行 Android 适配。适配版本移除了桌面图形代码，保留原始版权与 MIT 许可证，并增加当前项目的面片状态转换、固定三维坐标动作映射和阶段不变量验证。完整归属见 [`THIRD_PARTY_LICENSES.md`](../../THIRD_PARTY_LICENSES.md)。

## 回归验证

已针对 12、18、22 步的三组独立合法打乱执行端到端回归。每组均验证：六个阶段全部生成、层先法动作逐段应用后最终回到 `CubeState.SOLVED`。同时 Android 工程完整构建成功。
